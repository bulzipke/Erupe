# 요격전 승인된 대체 지도·에리어 랭킹 v1

2026-09-23. 사용자 승인 후 `custom-v1`으로 구현했습니다. 최초 메인 경로 제안에
분기 2개·보물·기존 수렵단 보수 수령·특별방 정보 플래그 연결이 추가 승인됐습니다.
단위·격리 DB 검증과 실제 게임 검증은 구분합니다. **운영 DB 변경·배포는 하지 않았으며,
실제 클라이언트 지도/입장/수령 화면 검증은 남아 있습니다.** 통합 운영 조건은
[지도 운영 안내](diva-map-operation.md)를 참고합니다.

## 원본과 대체안의 구분

[공식 최종 매뉴얼](https://web.archive.org/web/20191218054658id_/http://cog-members.mhf-z.jp/sp/manual/page399.html)에서
지도는 약 1시간마다 갱신하고, 현재 지도 초과 점수는 다음 지도에 넘기지 않으며,
분기 점수는 개인 점수에만 포함하고 메인 경로에서는 제외함을 확인했습니다.
에리어 랭킹은 수렵단의 획득 에리어 수를 사용하며 04·12·20시에 갱신됩니다.

아래의 지도 배치, 점수, 증가율, 정확한 정각 처리 및 동률 규칙은 **승인된 서버 전용 대체안**입니다.
40회 원본 복원 또는 원본 난이도와 동등하다고 주장하지 않습니다.
약 1시간이라는 공식 설명만으로 원본의 정산 기준 분·초나 최종 공개 지연을 확정하지 않습니다.

## 구현 범위: 메인 경로·분기·에리어 랭킹

- 시작점 1개와 획득 대상 20개를 둡니다. 마지막 목표도 20개에 포함됩니다.
- 모든 수렵단이 같은 회차·같은 지도 번호에서 같은 배치와 필요 점수를 사용합니다.
- 지도 배치를 고정하여 반복 사용하고, 지도 번호에 따라 필요 점수만 증가시킵니다.
- 몬스터는 선택한 퀘스트에 따릅니다. 지도마다 몬스터·타일 속성·보물을 무작위 배정하지 않습니다.
- 메인 5개·15개 획득 후 각각 단일 노드 분기를 해금합니다. 분기 좌표는 407·106이며,
  퀘스트는 각각 58079/58080 및 58081/58082/58083입니다. 분기당 기본 5,000점이고
  메인과 같은 지도별 배율을 적용합니다. 분기 점수는 메인 진행에 섞지 않습니다.
- 분기 에리어도 수렵단 누적 획득 수에 포함하므로 지도당 최대 22에리어입니다.
  보물은 분기마다 수렵단 티켓(ID 1026) 5개와 GP 500으로 승인됐습니다.
- 기존 5행 × 12열 UI, 현재/이전 지도 표시, 남은 필요 점수 표시를 사용합니다.
- 좌표·연결은 고정 대체표와 네이티브 순서/분기 포인터 검증을 사용합니다.
  정적 검증만으로 실제 게임의 육각격자 표시까지 검증됐다고 보지 않습니다.

### 첫 지도 필요 점수

| 획득 대상 | 칸당 필요 점수 | 구간 합계 |
| --- | ---: | ---: |
| 1~5번째 | 2,500 | 12,500 |
| 6~10번째 | 3,500 | 17,500 |
| 11~15번째 | 4,500 | 22,500 |
| 16~20번째 | 5,500 | 27,500 |
| 전체 20에리어 | — | **80,000** |

### 후속 지도

| 지도 번호 | 첫 지도 대비 필요 점수 | 해당 지도 전체 필요 점수 |
| --- | ---: | ---: |
| 1 | 100% | 80,000 |
| 2 | 125% | 100,000 |
| 3 | 150% | 120,000 |
| 4 | 175% | 140,000 |
| 5 이후 | 200%로 고정 | 160,000 |

계산은 정수로 수행합니다. 위 점수는 25% 단위에서 모두 정수가 됩니다.
지도 번호·수치의 패킷 한계를 넘으면 성공 응답을 보내거나 0으로 순환시키지 않습니다.

**분기를 제외하고 메인만 진행하며**, 지도 전환 때 초과 점수 폐기가 없을 때의 누적
필요 점수는 다음과 같습니다. 분기 점수와 분기 획득 에리어를 포함하면 합계가 달라집니다.

- 1에리어: 2,500점.
- 10에리어: 30,000점.
- 20에리어: 80,000점.
- 26에리어: 100,000점.
- 40에리어: 180,000점.

현재 보수표의 마지막 수렵단 달성 조건인 26에리어까지 **메인만으로 10만 점**을 기준으로 잡았습니다.
첫 지도 전체는 메인 80,000점이며 두 분기까지 모두 획득하면 22에리어·90,000점입니다.
이는 운영 로그로 검증된 난이도가 아닙니다. 예를 들어 **1인당 한 번에 5,000점을 얻는다고
가정**하면 혼자 20회 또는 동일 수렵단 4인으로 5회에 해당합니다. NPC는 별도 기여자로 세지
않습니다. 모두 정상 보고하고 메인 지도 기여 대상으로 인정되며, 지도 전환 시 초과 폐기가
없는 경우의 점수 계산일 뿐입니다. 정산 대기시간·실제 사냥 시간·실제 평균 점수는 반영하지
않았으므로 소요 시간 예측으로 사용하지 않습니다.

첫 클리어/반복 사냥/시간 보너스 구간을 구분해 실제 결과를 확인한 다음 조정하되,
확정한 지도표는 회차에 고정하고 운영 중인 회차의 난이도를 소급 변경하지 않습니다.

## 구현된 진행·집계 규칙

1. UTC+9 매시 정각에 미정산 기여를 반영합니다. 서버가 꺼졌던 구간은 저장된 시각과
   기여 원장으로 순서대로 복구하며, 조회만으로 임의의 보너스 진행을 만들지 않습니다.
2. 개인 요격 점수는 그대로 누적합니다. 지도 진행용 별도 기록을 소비하며, 지도 초과 점수를
   폐기해도 개인 달성 보수의 점수는 차감하지 않습니다.
3. 같은 수렵단의 인간 참가자별 최종 보고값을 각 1회 합산합니다. 4명이 각 5,000점이면
   합계 20,000점이며, 파티 인원이나 기존 보너스를 다시 곱하지 않습니다.
4. 출발 당시의 회차·수렵단·지도 번호와 퀘스트 종류를 고정합니다. 결과를 다시 보내거나
   서버가 재시작돼도 같은 기여로 에리어를 중복 획득하지 않습니다.
5. supplied `EventQuests.sql`의 유형 46/48로 확인된 퀘스트만 메인에 반영합니다.
   분기 퀘스트는 개인 점수와 해당 분기에 반영하며, 메인에서 제외합니다.
   58043~58128 전체를 자동으로 메인 퀘스트라고 간주하지 않습니다.
6. 정산 결과 목표까지 완료되면 새 지도로 원자적으로 전환하고 완료 지도를 이전 화면에
   남깁니다. 남는 지도 점수는 다음 지도로 이월하지 않습니다. 전환 전 지도에 귀속된
   늦은 결과도 새 지도를 진행시키지 않으며, 기간 내 유효한 개인 점수는 보존합니다.
7. 행사 종료 시 마지막 미정산분을 처리합니다. 종료 후 신규 결과 허용 기한은 기존 개인
   요격점수 정책을 임의로 늘리지 않습니다.
8. 0054 설치 시점을 영구 cutover로 저장합니다. 그 시점에 이미 시작한 실제 요격 회차는
   격리하며, **cutover 이후 새로 시작하는 실제 요격 회차**부터 지도 원장을 사용합니다.
   과거 개인 누적치나 진행 중 회차를 에리어로 소급 환산하지 않습니다.

## 구현된 랭킹 규칙

- 순위 기준: 실제로 획득한 에리어 수. 개인 요격 점수나 퀘스트 횟수를 대신 사용하지 않습니다.
- 공개: UTC+9 04·12·20시. 같은 경계에서 지도 정산을 먼저 끝내고 그 결과를 고정합니다.
- 동률: 1·1·3 방식 공동 순위. 같은 순위 안의 표시 순서만 수렵단 ID로 고정합니다.
  동률 정책은 원본 미확정이므로 이 부분은 서버 운영 규칙입니다.
- 목록은 최대 100개 수렵단, 자신의 수렵단은 100위 밖이어도 별도로 표시합니다.
- 종료: 마지막 정산 완료 후 최종 순위를 고정·공개합니다. 원본의 최종 집계 지연을
  확인한 것이 아니며, 다음 실제 요격 회차가 시작될 때까지 지난 확정 순위를 유지합니다.
- 기도의 장 수렵단 랭킹·보수는 별개입니다. 이 순위로 기도 보수를 지급하지 않습니다.

## 보수·특별 수렵단방 연결

현재 코드에는 수렵단 달성 2·3·5·6·8·10·20·22·24·26에리어 조건의 12개 보수 행이 있습니다.
22에리어에는 3개 보수가 있습니다. 직접 확인 6행/과거 회차 추론 6행의 구분과 수량은
그대로 유지하면서 **종류 7 조회·수령 확인·소재/GP 저장**에 연결했습니다.
개인 요격 달성 보수의 종류 6 수령 처리와 혼동하면 안 됩니다.

새로운 30·40에리어 보수는 만들지 않습니다. 해당 회차에서 출발 수렵단으로 검증된
개인 요격 점수 1점 이상, 현재 정회원, GR 및 실제 획득 에리어를 DB 잠금 후 검사합니다.
종류 5/7의 첫 발급 수렵단을 캐릭터·회차별로 고정하여 이적 중복을 막습니다.
미수령분은 다음 실제 요격전 시작 전까지이며, 완료 수령 재전송은 중복 지급하지 않습니다.

보물은 종류 5입니다. 같은 캐릭터·회차·지도·분기마다 티켓/GP 각 1회만 지급하며,
그 분기가 미완료인 동안 실제로 기여한 개인만 대상입니다. 같은 정산 구간의 파티원은
점수 상한 때문에 반영량이 0이 되어도 참여로 인정합니다. 완료 후 출발, 구지도 폐기,
다른 분기 참여는 자격을 만들지 않습니다. 이미 얻은 보물은 다음 지도에서도 수령할 수 있습니다.

[40회 공식 공지](https://web.archive.org/web/20191218001330id_/http://cog-members.mhf-z.jp/sp/news/14300.html)의
특별 수렵단방 1에리어 조건을 사용합니다. 남은 에리어는 1 또는 0을 반환하고,
`INFO_GUILD`의 특별방 플래그는 실제 회차의 가영 기간·조회 수렵단의 현재 정회원·1에리어
조건에서만 true입니다. 기도/전가 단계에 미리 켜지지 않습니다. **검증된 것은 서버 정보
플래그와 기간/자격 처리이며, 실제 특별방 입장 성공은 미검증입니다.** 기존 stage 입장
핸들러에 별도의 특별방 권한 검사가 있지는 않습니다. 선율 잔액·교환은 여전히 미구현입니다.

## 검증과 남은 실게임 확인

- 퀘스트별 메인/분기 분류·패킷 범위는 코드/테스트로 확인했습니다. 실제 UI 좌표는 미검증입니다.
- 같은 결과 재전송, 동시 정산, 재시작 복구에서 중복 에리어 없음.
- 0점, 임계값 직전·정확 도달, 한 번에 여러 칸, 목표 초과 폐기.
- 회차·지도 전환을 가로지르는 출발/귀환과 수렵단 이동.
- 정각 정산과 랭킹 공개 경쟁, 종료 시각 마지막 정산, 지난 확정 순위 유지.
- 100위 밖 자기 수렵단, 동률, 한글 이름, 현재/이전 지도 화면.
- 개인 점수·개인 보수·기도 랭킹 회귀 검사.

위 서버 동작은 단위·격리 DB race 테스트로 확인했으며, 테스트 성공을 실게임 입장·렌더링·
수령 검증 완료로 간주하지 않습니다. 운영 DB 변경·배포는 수행하지 않았습니다.

서버가 최종 요격 점수를 독립적으로 재계산하는 구조는 현재 아닙니다. 지도 원장의 멱등성과
소유권 검증을 구현해도 조작된 클라이언트 점수까지 완전히 검증했다고 주장하지 않습니다.
