# 요격전 HR 수렵단 달성 보수

2026-09-23. HR 수렵단 보수도 기존 보상을 바탕으로 채워 달라는 운영자 요청에 따른
**서버 전용 대체표**입니다. 40회차 또는 다른 회차의 원본 복원표가 아닙니다.
기도의 장 수렵단 **랭킹** 보수와는 별개인, 전가의 장 요격전 **획득 에리어** 보수입니다.

## 지급표

GR 표와 같은 10개 에리어 단계에 HR 개인 요격 보수에서 사용 중인 수렵단 티켓과 GP를
배치했습니다. HR은 공통 표를 사용하며 GR 보수의 품목·수량·조건은 변경하지 않습니다.

| 획득 에리어 | 해당 단계 보수 |
| ---: | --- |
| 2 | 수렵단 티켓 5개 |
| 3 | 수렵단 티켓 10개 |
| 5 | GP 100 |
| 6 | 수렵단 티켓 10개 |
| 8 | GP 200 |
| 10 | 수렵단 티켓 10개 |
| 20 | GP 300 |
| 22 | 수렵단 티켓 20개 |
| 24 | GP 400 |
| 26 | GP 500 |

모든 단계를 HR로 수령했을 때 합계는 **수렵단 티켓 55개 + GP 1,500**입니다.
각 행은 누적 총량이 아니라 해당 단계에서 추가 지급하는 양이며 반복 보수는 없습니다.
아이템 ID는 1026(0x0402), GP는 기존 보수 종류 26입니다.

## 표시와 지급

- 대상은 저장 랭크 HR 2~999, GR 0입니다. 기존 HR 보수와 같은 범위를 사용합니다.
- 기존 클라이언트 보수 목록의 HR 구분으로 10행을 전송합니다. GR 캐릭터도 HR 표를
  미리 볼 수 있지만 HR 대체표를 새로 지급받지는 않습니다. 클라이언트 수정은 없습니다.
- 현재 수렵단 정회원, 해당 회차·수렵단에서 검증된 요격 참여, 실제 획득 에리어를 검사합니다.
  개인 누적 점수를 에리어로 환산하거나 가입만으로 보수를 주지 않습니다.
- 지도 활성화·정산·보물·특별방 조건은 변경하지 않습니다. 기존과 동일하게 다음 실제
  요격전 시작 전까지 수령할 수 있습니다.
- 표시 목록 조회는 보수 선택을 고정하지 않습니다. 수령 가능 보수 조회에서 영수증을
  처음 발급할 때 **회차·캐릭터·에리어 단계별 HR/GR 중 하나**를 고정합니다.
- HR 보수를 발급받은 뒤 GR로 승급해도 그 단계의 미수령 HR 보수는 보존됩니다.
  같은 단계의 GR 보수를 추가로 받지는 않으며, 아직 발급되지 않은 단계는 새 랭크를 따릅니다.
  22에리어 GR의 3개 품목은 하나의 단계 묶음입니다. 이후 새 회차는 별도로 선택합니다.
- 재전송·재접속은 같은 영수증을 사용합니다. 소재는 SAVEDATA, GP는 GP 저장과 함께 수령
  완료되며 저장 실패 시 미수령 상태를 유지합니다.

## 적용

HR 표는 `diva_hr_guild_rewards.go`에 있습니다. 기존 `diva_prizes` GR 표는 수정하지 않습니다.
`0057_diva_hr_guild_reward_groups.sql`은 다음 서버 시작 때 자동 적용되며, 기존 GR의
미수령·수령 완료 영수증 모두에 단계별 선택 이력만 보강합니다. 영수증 ID·수량·수령 시각은
바꾸지 않습니다. 운영 DB 수동 변경, 배포, 클라이언트 패치는 수행하지 않았습니다.

격리 DB/패킷 테스트와 실제 인게임 표시·수령 검증은 구분해야 합니다.
