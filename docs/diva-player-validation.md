# 가희수위전 인게임 확인표

2026-09-23. 서버 코드/DB 테스트와 실제 화면·효과 검증은 구분합니다.
현재 작업은 클라이언트 패치, 운영 DB 수정, 배포를 포함하지 않습니다.

## 먼저 확인할 조건

- 최신 서버를 실행할 때 자동 마이그레이션 0059~0062가 정상 완료되어야 합니다.
- 특별방은 실제 맞이의 장(가영의 장) 기간 + 수렵단 획득 에리어 1개 이상 +
  현재 정식 단원 조건입니다. `DivaOverride=3`만으로 실제 기간/획득 조건을
  우회하지 않습니다. 시계 강제 옵션도 이용권을 만들지 않습니다.
- 새 v3 지도는 이후 실제 새 회차부터 적용됩니다. 진행 중인 v1/v2 회차를
  새 규칙으로 덮어쓰거나 점수·수령 기록을 초기화하지 않습니다.
- 동행자 설정은 실제 전가의 장, GR1 이상에서 확인합니다.

퀘스트 번호도 필요합니다. 계정 토큰·비밀번호·전체 세이브 데이터는 필요하지 않습니다.

## 정적 확인으로 확정하지 않은 범위

- 무료 노래의 설명은 내장 도움말 `mhfpac.csv` pointer-slot 1285780~1285828에서
  확인했지만 정확한 송신/수신 효과 경로까지 확정하지는 못했습니다.
  특별방 플래그 참조와 맵 445 분기를 읽기 전용으로 확인했으며, 근거 없는
  서버 효과 값이나 별도 노래 패킷을 만들지 않았습니다.
- 선율 교환과 별개인 특별방 수렵단 티켓 추가 교환은 원본 기능 설명에
  등장합니다. 실제 클라이언트 메뉴/품목과 서버 요청 유무는 추가 확인 대상입니다.
- 별도 요격전 순위별 보수표는 [재조사](diva-interception-ranking-audit.md)에서도
  존재를 확정하지 못했습니다. 현재의 개인·수렵단 달성 보수와 구별해야 합니다.
- HR 선율, 지도 특수요소 수치와 일부 보수는 승인된 서버 대체/추론 데이터입니다.
  원본과 완전히 동일하게 복원했다는 의미는 아닙니다.
