# 선율 교환품 76종 복원

2026-09-23. 이전 42종에 외장권 26종·실크/천 8종을 추가했습니다.
서버 소스만 변경하며 운영 DB, 잔액, 기존 보수 영수증, 클라이언트 파일은 변경하지 않습니다.

## 확인과 추론의 구분

- **품목·비용:** [최종 공식 교환표](https://web.archive.org/web/20191215192228id_/http://members.mhf-z.jp/contents/regular_event/diva/change_item.html)의 76행과 일치합니다.
- **아이템 ID:** [일본어 Ferias item.js](https://ferias.life.coocan.jp/sozai/item.js)를 CP932로 읽고 공식 이름의 전각/반각을 정규화하여 36개 외장권/생산 소재를 각각 유일한 ID와 대조했습니다. 번역 이름·설명은 런타임 데이터로 캐싱하지 않습니다.
- **지급 수량:** 모두 1개입니다. 공식 HTML에는 별도 지급 개수 열이 없으므로 76행 모두의 40회 교환 화면을 직접 확인했다는 뜻은 아닙니다.
- 카탄테·리칸테는 [당시 직접 플레이 설명](https://mhf-akia.blog.jp/archives/1066245293.html), 우탄테는 [14회 안내](https://capcir.blog.fc2.com/blog-entry-1475.html), 歌詠ノ布는 [19회 안내](https://capcir.blog.fc2.com/blog-entry-1530.html), 샨루는 [28회 안내](https://capcir.blog.fc2.com/blog-entry-1605.html)에서 소재 1개당 선율 2개를 명시합니다.
- 歌紡ノ布는 [추가 당시 설명](https://blog.livedoor.jp/guild5_mhf/archives/76873620.html)에서 선율 2개로 생산 소재 1개라고 설명합니다.
- 메렌테는 [추가 당시 안내](https://capcir.blog.fc2.com/blog-entry-1448.html)에서 비용 2를 확인하지만 별도 수량은 명시하지 않습니다. 메렌테·프란테·판루·뮨루의 **수량 1은 위와 동일한 생산 소재 계열의 교환 단위로 추론**했습니다.
- 외장권은 [당시 플레이 기록 목록의 「2016最後の近況報告」](https://plaza.rakuten.co.jp/alioth/diaryall/)의 선율 3개로 카탄테 한 부위와 메란 외장을 교환한 설명 및 [초기 교환 안내](https://mhfteamw.blog.fc2.com/blog-entry-41.html)의 외장권 비용 1을 대조했습니다. **각 외장권 26종의 개별 지급 화면까지 검증한 것은 아니며, 같은 교환 계열의 수량 1로 추론**했습니다. 오래된 장식품 비용 3은 채택하지 않고 최종 공식 비용 1을 유지합니다.

기존 요청의 검증/강한 역사적 추론 범위로 적용했으며, 확률·최대 선율·획득 점수는 바꾸지 않습니다.
새 소재를 같은 카테고리라고 무조건 추가하지 않고 아래 공식 목록만 허용합니다.

## 호환성

HD `11528fe0`의 조회 한도는 `0x200=512`, 수신 버퍼는 `0x4400`바이트입니다.
ZZ 76행은 헤더 포함 2,284바이트로 이 범위에 들어갑니다. 상품 ID는 계속 아이템 ID이므로
표시 순서 변경으로 월렛이나 수령 영수증 식별자가 바뀌지 않습니다. 한 번의 교환은 원본대로
선택 상품 1개이며, USE 응답을 받은 클라이언트가 지급합니다. 서버가 재지급하지 않습니다.

외장권 26종 추가로 선율 1개 상품은 66종, 선율 2개 상품은 10종입니다.
교환 자격, 계정 공유, 기간 만료, 부족 잔액 거절과 요청 비용 1/2 검사는 그대로입니다.
단순 상품표 확장이므로 이번 추가분에는 DB 마이그레이션이 없습니다.
