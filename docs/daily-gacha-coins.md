# 일일 접속 뽑기 코인

계정 공용 유료 코인 잔액 `users.gacha_premium`에 자동 지급한다.
안내에서는 무료·유료를 구분하지 않고 '뽑기 코인'으로 표기한다.
한국 시간(UTC+09) 오전 0시부터 다음 0시까지를 하루로 계산한다.
컨테이너 시간대나 게임 내 시간 변경 설정은 영향을 주지 않는다.

- 게임에 입장한 첫 접속: 10개.
- 그날 누적 접속 1시간: 추가 10개, 하루 한 번.
- 재접속·채널 이동·캐릭터 교체: 같은 계정의 누적 시간을 이어서 사용한다.
- 동시 접속: 겹친 시간은 한 번만 계산한다.
- 자정에도 접속 중이면 새 날짜의 10개를 지급하고 새 날짜의 1시간을 계산한다.
- 전날의 미달 시간은 다음 날로 이월하지 않는다. 오프라인 시간은 제외한다.
- 일일 제한 20개는 이 접속 보상의 지급 한도이며, 기존 코인 잔액이나 다른 배포를 제한하지 않는다.
- 넷카페 코스가 없어도 지급한다. 런처 및 캐릭터 생성 화면은 제외한다.

기본 활성화. 끄려면 `GameplayOptions.DisableDailyGachaCoins: true`를 설정한다.
신규 서버 실행 시 마이그레이션 0041이 `daily_gacha_coins` 테이블을 생성한다.
운영 DB에 수동 SQL을 실행할 필요는 없다.

잔액 증가와 날짜별 지급 기록을 동일 트랜잭션으로 저장한다. 지급 기록은 코인
소비와 독립적이므로 코인을 사용하거나 재접속해도 다시 지급되지 않는다.
15초 간격으로 접속 구간을 저장하고 정상 종료 시 남은 구간도 정산한다.
프로세스 강제 종료 시 마지막 저장 이후의 미저장 구간(정상 DB 상태에서 약 15초)은
유실될 수 있지만 이미 지급한 코인과 기록은 유지된다. DB 오류 시 연결이 살아 있는
동안 미저장 구간을 재시도하며, 종료 시에는 한 번 더 재시도한다.

알림은 개인 서버 채팅으로 보낸다. 남은 분은 올림하여 안내한다.
- 첫 접속/자정: 첫 접속 10개 획득 → 남은 시간 → 보유 개수 (3줄).
- 누적 1시간: 추가 10개 획득 → 보유 개수 (2줄).
- 추가 보상 전 재접속: 남은 시간 → 보유 개수 (2줄).
- 당일 보상 완료 후 재접속: 보유 개수 (1줄).

보유 개수 문구는 `뽑기 코인 보유: N개`이다.
20개를 모두 받은 날 재접속하면 완료 안내 없이 보유 개수만 보낸다.
보유 개수는 같은 정산 트랜잭션에서 확인한 유료 코인 잔액이다.
일반 맵 이동마다 반복하지 않는다.
한 안내의 모든 줄을 한 전송 묶음으로 큐에 넣으며, 큐가 차면 빈자리를 기다린다.
개별 줄을 버리는 기존 비차단 전송 경로는 이 안내에 사용하지 않는다.
서버 로그의 `Daily gacha coin notice`에 계정·캐릭터·날짜·안내 종류·잔액·줄 수를 기록한다.
DB 반영 후에만 획득 안내를 전송한다. 가챠 잔액은 기존 조회 응답으로 갱신되며,
이미 열려 있는 클라이언트 화면의 즉시 갱신은 보장하지 않는다.

기존 무료 코인을 자동 전환하거나 가챠 소비 규칙을 변경하지는 않는다.
