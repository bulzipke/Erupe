# 특별 수렵단방 모험 특전

## 이번 보완

기존 `MSG_MHF_REGIST_GUILD_ADVENTURE_DIVA`의 1시간 귀환 처리를 유지하면서,
등록 권한을 서버의 실제 특별 수렵단방 자격과 연결했습니다.

- 현재 캐릭터가 정식 단원이고 현재 수렵단이 해당 회차 지도에서 1구역 이상 획득해야 합니다.
- 실제 맞이의 장 기간에만 출발할 수 있습니다. `DivaOverride=3`만으로 실제 기간을 우회할 수 없습니다.
- 입단 신청 중인 캐릭터, 탈퇴한 캐릭터, 이전 수렵단의 권리를 재사용하는 캐릭터는 등록할 수 없습니다.
- 단장 전용은 아닙니다. 자격 있는 수렵단의 새 정식 단원도 개인 요격 기록 없이 이용할 수 있습니다.
- 캐릭터/수렵단/회원/회차 상태를 DB 잠금 아래 검사하고 같은 트랜잭션에서 등록합니다.
  대기 잠금 이후 DB 시각을 다시 검사하므로 종료 직전 대기한 요청으로 기간을 우회하지 못합니다.
- 등록 성공 시점부터 정확히 1시간 뒤 귀환합니다. 이미 출발한 모험은 방 운영 기간이 종료되어도 유지합니다.
- 등록 실패 시 성공한 것처럼 응답하지 않고 기존 프로토콜의 실패 ACK를 돌려줍니다. 연결을 끊지 않습니다.

일반 모험의 6시간 귀환, 모험 수령/지원, 특별 모험 패킷의 목적지·초기 지원량 값은 변경하지 않았습니다.
확인되지 않은 목적지 목록, 지원량 배율, 추가 비용을 임의로 도입하지 않았습니다.
구형 클라이언트와 게임 내 시각 강제 변경 상태는 다른 특별방 쓰기 기능과 동일하게 허용하지 않습니다.

## 인게임 확인이 필요한 부분

1. 맞이의 장에 1구역 이상 획득한 수렵단으로 특별방에 입장합니다.
2. 모험을 출발시키고 모험 목록의 귀환 예정 시간이 약 1시간 뒤인지 확인합니다.
3. 다른 정식 단원에게도 같은 모험이 보이는지 확인합니다.
4. 1시간 뒤 수령이 가능하고, 목적지별 보수와 지원량이 종전과 동일한지 확인합니다.
5. 종료 경계에서 거절되는 경우 메뉴가 정상으로 돌아오는지 확인합니다.

서버는 아직 확인되지 않은 클라이언트 보상 계산을 바꾸지 않습니다. 특히 목적지별 추첨표나
특별방의 최종 보수 증가량까지 새로 구현했다는 의미는 아닙니다. 이번 변경은 기존 1시간
모험 기능에 누락돼 있던 기간·수렵단 자격 검사와 정확한 실패 응답을 연결한 것입니다.
